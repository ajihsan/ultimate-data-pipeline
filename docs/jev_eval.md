Real-model decision-quality and latency report for the decide pipeline's
model path. Checkpoint: `convaiinnovations/laya-typed-decisions` (421M,
ModernBERT-large encoder). Generated by `udp-eval`. Regenerate with `make
model` running, then `uv run udp-eval --count 600 --rate 5`.

The tables above are the current results. Text marked SUPERSEDED is history.
Do not use it as a current measurement.

## Method

`udp-eval` generates seeded tickets with the production generator (profile
`steady`, seed 7). `category_hint` is ground truth and is never published on
the wire. Each labeled ticket is POSTed to the running model server
(`http://127.0.0.1:8082/v1/systemone`) with the exact question payload that
decide.yaml sends:
`{"escalate_now": {"type": "noul"}, "category": {"type": "choice", ...}}`.
The eval uses an 8-worker thread pool paced at 5/s (rate 0 = closed-loop).

It sent 572 labeled and 28 ambiguous tickets. Latency is end-to-end HTTP per
request. It includes the server's cohort batching. At this rate cohorts are
1–2 states. Brier for escalate_now uses the documented scam-proxy label
(scam_report = 1, everything else = 0). The synthetic stream has no true
escalation label, so treat it as a discrimination check.

## Thresholds

The notify pipeline consumes the defaults `THRESHOLD_ESCALATE_P=0.75` and
`THRESHOLD_SCAM_P=0.35`. The final values in `.env.example` use the p(scam)
sweep above (precision, recall, and F1 per cutoff) and the escalate_now
distributions. p(scam) separates cleanly, with a scam-class mean of 0.67 and
0.03 for the other classes. The chosen `THRESHOLD_SCAM_P` sits inside that
separation band. escalate_now ships temperature 1.98 (smoothed toward 0.5), so
its cutoff needs wider margins than the raw spread suggests. See the sweep
JSON.

## Temperature-clamp note

At load, laya clamps the checkpoint's shipped `choice:11+` temperature
(0.1006) to 0.5, its sanity floor, and the server logs a `RuntimeWarning`. The
6-option category head does not use that bucket. Six options land in
`choice:6-10` (shipped temperature 1.0000), so category confidence stays
calibrated. The `noul:2` head ships temperature 1.9834, which smooths
escalate_now toward 0.5. The p95 column above shows this. Use wider margins.

## Limitations

- Ticket texts come from 6 synthetic template pools per class. Real-ticket
  vocabulary will differ. category_hint is generator ground truth, not human
  labels.

- Note the complaint class. Its templates name technical symptoms
  ("sync is broken", "logged out"). Both the model and the fast-path rule table
  classify by that symptom. Treat that row as a label-definition artifact, not
  pure model failure.

- escalate_now has no ground truth here (scam-proxy label, see Method). Its
  head also ships temperature 1.98, which halves the raw logit separation.

- The server coalesces concurrent requests into `predict_batch` cohorts
  (batch 8). Throughput rises to ~12.6 tickets/s closed-loop, but each cohort
  completes together. Saturated-load latency is about cohort latency (~0.6 s).

- This is a single GPU box shared with other homelab workloads (jellyfin). The
  numbers were taken while co-tenancy was idle. See the early gate history and
  issue #10 comment for the amd-smi snapshots.
